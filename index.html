O PROJETO

Uma escola pensada para o futuro

O projeto Escola Sustentável com Energia Eólica foi desenvolvido na Sala Maker CE-397, transformando conhecimento em uma experiência prática de aprendizagem.

A proposta consiste na construção de uma maquete de uma escola que utiliza a energia eólica como fonte de geração de energia.

Durante o desenvolvimento, os estudantes podem acompanhar o planejamento, a construção, a montagem e os testes do sistema. Nesta etapa, os geradores são movimentados por uma bateria para demonstrar o funcionamento do mecanismo, enquanto trabalhamos no desenvolvimento de uma solução que permita movimentá-los efetivamente pela força do vento.
